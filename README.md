
# Projet 3D interactif – Three.js

## Description
Ce projet est une applicatio web permettant d’afficher et d’interagir avec une scène 3D directement dans le navigateur pour un projet d'entreprise fictive.  
Il a été développé en JavaScript à l’aide de la bibliothèque Three.js dans un objectif d’apprentissage du développement web interactif et de la 3D temps réel.

## Objectifs
- Découvrir les bases de la 3D dans le navigateur
- Comprendre le fonctionnement d’une scène Three.js
- Mettre en place des animations et des interactions utilisateur
- Approfondir les bases du développement JavaScript

## Technologies utilisées
- JavaScript
- Three.js
- HTML / CSS
- WebGL
- Blender

## Fonctionnalités
- Affichage d’une scène 3D
- Animation d’objets
- Interaction avec l’utilisateur (caméra, rotation, clic, etc.)
- Gestion de la lumière et du rendu
